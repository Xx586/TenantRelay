# 演示指南

## 推荐演示顺序

1. 打开 Web 工作台，填写 `demo-tenant` 和本地演示 API Key。
2. 发送“Python SDK 上传接口返回 403，我们刚降级到 basic 套餐”。
3. 展示主意图、次级意图、Integration/Subscription 协作和工具 Trace。
4. 打开 SaaS 工作台，查看租户配置、套餐权限和白名单服务状态。
5. 显式创建工单，记录返回的 `TR-...` 编号。
6. 使用工单编号再次查询，证明结果真实持久化且校验租户归属。
7. 打开知识库和评测页面，说明租户过滤与指标来源。

不要把未实际运行得到的准确率、成功率或延迟写入简历。
