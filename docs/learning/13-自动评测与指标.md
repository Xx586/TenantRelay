# 13 自动评测与指标

## 本章解决什么问题

学会用数据集而不是主观感觉评价意图、路由、工具和租户隔离。

## 小白类比

只演示一道会做的题不等于考试高分；评测集是项目的模拟卷和成绩单。

## 前置知识

了解样本、预测标签、真值标签、混淆矩阵、Precision 和 Recall。

## 源码阅读顺序

`evaluation/saas_cases.py` → `evaluation/evaluator.py` → `/eval/run` → `tests/test_saas_scenario.py`。

## 核心类和函数解释

`build_saas_eval_cases()` 生成每类至少 15 条意图用例；复合问题、多轮对话、工具故障和租户隔离分开建模。`EndToEndEvaluator` 执行端到端请求并汇总指标。

## 一次真实输入如何流转

“Python SDK 403 且刚降级套餐”→标准答案指定 SDK 错误主意图和权限辅意图→真实调用意图识别和路由→比对 Integration/Subscription 组合→累计准确率。

## 可执行实验

在 SaaS 模式调用 `POST /eval/run`，保存返回的逐条结果；再对错误样本分类，区分意图、实体、路由和工具错误。

## 常见错误

把伪造或未实际执行的数字写进简历；测试集与 Prompt 完全重复；只看 Accuracy，不看小类别的 Macro-F1。

## 自测题及答案

问：为什么多类意图要看 Macro-F1？答：它先对每类计算 F1 再平均，避免大类别数量掩盖小类别表现。

## 面试表达

“我把单意图、复合路由、多轮、工具故障和租户隔离分层评测，只报告在 Python 3.12 容器中实际运行得到的指标。”
