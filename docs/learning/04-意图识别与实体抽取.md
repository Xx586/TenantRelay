# 04 意图识别与实体抽取

## 本章解决什么问题

理解为什么“它想做什么”和“句子里有什么关键数据”要分开。

## 小白类比

“我要坐明天去上海的车”：意图是购票，实体是明天和上海。

## 前置知识

了解 Enum、正则表达式和余弦相似度的概念。

## 源码阅读顺序

`IntentCategory` → `_TEMPLATES` → `_pattern_recognize` → `_vote` → `_extract_entities` → `_secondary_intents`。

## 核心类和函数解释

- LLM 理解语义，字符 n-gram 处理相似说法，Pattern 捕获高精度信号。
- 主意图决定主 Agent，`secondary_intents` 驱动辅助 Agent。
- 实体包括错误码、API 路径、SDK 版本、套餐和环境。

## 一次真实输入如何流转

“Python SDK v2.3 调用 POST /uploads 返回 403”先命中 SDK 错误规则，再抽取语言、版本、方法、路径和错误码，最后补出权限辅意图。

## 可执行实验

运行 `pytest tests/test_saas_scenario.py -k entities -q`，再把测试句中的 403 换成 429。

## 常见错误

认为 LLM 一定比规则准。强格式字段用正则更稳定、更便宜。

## 自测题及答案

问：为什么 403 可能同时触发 SDK 和套餐 Agent？答：它既可能是调用问题，也可能是套餐或租户权限。

## 面试表达

“单标签识别负责主路由，再用可解释的辅助意图规则支持复合问题。”
