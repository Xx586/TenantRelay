# AcmeCloud 集成故障排查手册

## 401 认证失败

1. 检查租户 ID 和 API Key 是否属于同一环境。
2. 检查 Token 是否过期以及客户端时间是否同步。
3. 不要把完整密钥复制到聊天、日志或工单。

## 403 权限不足

1. 查询当前套餐是否包含目标功能。
2. 检查租户功能开关和 IP 白名单。
3. 保留脱敏后的 request_id，持续失败时再创建工单。

## 429 请求过多

1. 使用指数退避并设置最大重试次数。
2. 查询套餐配额和调用频率限制。

## Webhook 失败

依次检查 HTTPS 证书、签名原文、时间戳、响应状态码和处理耗时。状态检查只允许访问平台预配置的白名单服务。
